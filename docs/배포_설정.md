# 자동 배포 설정 (한 번만)

`main` 에 머지되면 Firebase Hosting 에 자동 배포된다. 그러려면 **저장소 시크릿 2개**를 한 번만 넣어야 한다.
넣기 전까지는 워크플로가 "시크릿 없음" 으로 멈추므로, 잘못된 사이트가 배포될 일은 없다.

> ⚠️ 이 저장소는 **공개(public)** 다. 시크릿은 GitHub 금고에만 저장되고 로그·소스에 찍히지 않으며,
> 외부인이 만든 fork PR 에서는 아예 주입되지 않는다(워크플로가 `push`/`workflow_dispatch` 로만 돈다).

## ① `ENV_FILE`

로컬 `.env` **내용을 통째로** 붙여 넣는다.

```powershell
cd I:\ttong_project\wellshare-logis-web
type .env | clip      # 클립보드로 복사
```

- Name: `ENV_FILE`
- Secret: 붙여넣기 (여러 줄 그대로)

```
VITE_FIREBASE_API_KEY=...
VITE_FIREBASE_AUTH_DOMAIN=...
VITE_FIREBASE_PROJECT_ID=...
VITE_FIREBASE_STORAGE_BUCKET=...
VITE_FIREBASE_MESSAGING_SENDER_ID=...
VITE_FIREBASE_APP_ID=...
VITE_ECOUNT_GATEWAY_URL=...        (있으면 같이)
```

**왜 필요한가**: `src/firebase.ts` 가 이 값들을 **빌드 시점에** 번들에 박아 넣는다.
없이 빌드하면 Firebase 설정이 `undefined` 인 번들이 나가서 **로그인부터 안 되는 사이트**가 배포된다.

## ② 배포 인증 — 아래 둘 중 **하나만**

### 방법 A: CI 토큰 (간단·권장)

형 PC에서 한 줄이면 끝난다.

```powershell
firebase login:ci
```

브라우저가 열리고 로그인하면 터미널에 `1//0e...` 형태의 토큰이 찍힌다. 그걸 복사해서:

- Name: `FIREBASE_TOKEN`
- Secret: 토큰 값

> ⚠️ 이 토큰은 형 계정 권한을 그대로 갖는다. 채팅·메모에 남기지 말고 GitHub 시크릿에만 넣을 것.
> 유출됐다 싶으면 `firebase logout --token <토큰>` 으로 즉시 무효화한다.

### 방법 B: 서비스계정 (권한을 좁히고 싶을 때)

1. https://console.cloud.google.com/iam-admin/serviceaccounts?project=wellshare-logis
2. **서비스 계정 만들기** → 이름 아무거나 (예: `github-deploy`)
3. 역할 부여: **Firebase Hosting 관리자** + **API 키 뷰어** (`serviceusage.serviceUsageConsumer` 포함 역할)
4. 만든 계정 → **키** → **새 키 만들기** → JSON → 다운로드
5. 그 JSON 파일 내용 전체를 시크릿으로:
   - Name: `FIREBASE_SERVICE_ACCOUNT`
   - Secret: JSON 통째로

둘 다 넣으면 서비스계정이 우선 쓰인다.

## 확인

시크릿 2개를 넣은 뒤 **Actions 탭 → 배포 (Firebase Hosting) → Run workflow** 를 눌러 본다.

- 초록불 → https://wellshare-logis.web.app 접속해서 확인
- 빨간불 → 로그를 열면 어디서 막혔는지 나온다. 그대로 캡처해서 보내주면 된다.

이후로는 `main` 에 머지될 때마다 자동으로 돈다.

## 이 워크플로가 하는 일 / 안 하는 일

| 한다 | 안 한다 |
|---|---|
| `npm ci` → `npm run lint` → `npm run build` | `functions` 배포 |
| 통과했을 때만 **hosting** 배포 | `firestore.rules` · `storage.rules` 배포 |
| 배포 요약을 Actions 화면에 남김 | 실패한 빌드 배포 |

규칙·함수 배포는 사고 위험이 커서 일부러 뺐다. 필요하면 수동으로:

```powershell
firebase deploy --only functions
firebase deploy --only firestore:rules,storage:rules
```
